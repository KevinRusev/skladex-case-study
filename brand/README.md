# Brand

Visual language of the skladex.bg storefront. Industrial and high-contrast: warehouse
yellow on near-black, with condensed display type.

## Colour

| Role | Hex |
|---|---|
| Signal yellow (primary, buttons, accents) | `#FFC907` |
| Deep yellow (borders, hover) | `#E5B200` |
| Ink (dark sections, top bar, text on yellow) | `#0D0E11` |
| Body text | `#16181D` |
| Paper | `#FFFFFF` |
| Paper 2 (page heads, panels) | `#F4F5F7` |

## Type

- **Headlines:** Sofia Sans Extra Condensed, Black, uppercase, tight line height
- **UI and display accents:** Montserrat
- **Body:** Inter
- **Labels, breadcrumbs, kickers:** JetBrains Mono, uppercase, wide tracking

## Shape

- Primary buttons are slanted (a slight skew) with an upright label, a nod to warehouse
  hazard tape.
- Rounded cards and panels with a soft shadow; yellow outline on the main summary and form cards.

The logo and product photography belong to the client and are not included in this repository.
